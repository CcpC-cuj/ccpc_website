# CcpC Website
This the is the offical website of the Code Crafters Programming Club, Here we get the updates and the events details of the club with the deatils of each members of the club.

## Admin Frontend (Local)
- Run: `npm start`
- Frontend env (optional): `REACT_APP_API_BASE_URL=http://localhost:3000`
- Backend must be running at http://localhost:3000 for local dev.
- Production backend: https://ccpccuj-mem-reg-2026.hf.space
